# weekend-agent-demo

AI Agent 周末旅行规划教学 Demo，展示任务拆解、工具调用、反馈调整与预算核对。

在线演示：https://tangx2872-svg.github.io/weekend-agent-demo/

## 使用

直接打开 index.html，或访问 GitHub Pages。

- 晴天：分步骤生成示例计划。
- 下雨：根据模拟天气调整行程。
- 预算 500 元：发现预算不足后请求确认。
- 一次回答：与预设的分步骤流程对照。
- 支持下一步、自动播放/暂停、重置和下载执行记录。

## 教学说明

本项目是规则驱动的流程模拟，不调用真实大模型或在线天气、地图接口。天气、费用、地点与营业信息均为预设示例，不能作为真实出行依据。不会购买、支付或预约。

预算默认已到杭州，不含城际往返；两天住宿按 1 晚计算。
