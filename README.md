# weekend-agent-demo

AI Agent 执行闭环的规则模拟教具。没有真实LLM，也不访问实时天气地图或产生订单。

- 交互实验台：https://tangx2872-svg.github.io/weekend-agent-demo/
- 参数纠错投影版：https://tangx2872-svg.github.io/weekend-agent-demo/projection.html
- 上一版轨迹界面：trace-v1.html；最初旅行流程：legacy.html。

## 准确性边界

目标仍为杭州两天一晚，当地预算1000元（不含城际往返）；日期10月31日—11月1日是教学设定。但现有工具fixture只覆盖10月31日的一条候选路线和费用快照，不足以验收整趟两日游。

walk_km=1.2仅为本次候选路线结果；<=2 km是本演示检查阈值，不是用户原话，不能解释为全程或单日总步行。

雨天费用：交通140+住宿360（1晚）+餐饮240+活动60+备用100=900元。没有逐日安排、全程距离或真实授权系统。final_answer表示本次规则模拟输出结束，未证明完整旅行任务已完成。

## 规则测试

20条=2种天气×5档预算×2种参数状态。16条现有候选预算可行，固定模板通过8/16，反馈控制器16/16。另4条现有900元候选超预算，均询问用户，不表示500元不可能旅行。

恢复10/10全部为可修复城市参数错，不含持续超时。反馈控制器全部20条共110次工具调用，平均5.5次，包括失败请求，不包括final_answer和ask_user终止输出。

控制器和验收器代码仍为原有engine.js，本次只修改界面披露和增加投影回放，不新增消融或模型性能结论。

## 演示

在主界面注入wrong_city，观察拒绝、修正和新动作；持续超时最多尝试2次（含首次）；总调用预算8。也可打开projection.html逐次演示可读的状态、请求和返回。两个HTML都须与engine.js放在同目录才能离线运行。

参考：Yao et al., ReAct, ICLR 2023，https://arxiv.org/abs/2210.03629
